================================================================
circRNA-seq analysis pipeline  (CIRI2 + CIRIquant)
HNSCC tumor/normal, RNase R treated + ribo-depleted, paired-end
================================================================

DATA / KEY FACTS
----------------
- Libraries: RNase R treated, ribo-depleted total RNA, paired-end, tumor/normal pairs.
- Strandedness: REVERSE (RF / fr-firststrand). Confirmed empirically with RSeQC
  infer_experiment.py -> 0.83 reverse / 0.02 forward / 0.15 undetermined.
    -> CIRIquant  --library-type 2
    -> nf-core/circrna samplesheet  strandedness: reverse
    -> CIRI2 itself has NO strand option; its step is unaffected.
- RNase R caveat: enrichment helps DETECTION but breaks QUANTIFICATION
  (linear / forward-splice-junction reads are digested, so junction ratio is
  meaningless). Accurate expression requires a matched RNase R(-) "mock"
  (total RNA) library per sample + CIRIquant --RNaseR correction. Without a
  mock, report BSJ counts / CPM only.

REFERENCES  (same build as the rest of the HNSCC pipeline)
---------------------------------------------------------
- Genome: GRCh38.primary_assembly.genome.fa   (GENCODE-distributed)
- Annotation: gencode.v50.annotation.gtf
- Indexes / derived files (build once, reused):
    bwa index -a bwtsw            (CIRI2 alignment)
    hisat2-build                  (CIRIquant hisat_index input)
    samtools faidx
    GTF -> BED12 (gtfToGenePred | genePredToBed)   (RSeQC QC only)

ENVIRONMENTS
------------
- conda env "circrna": fastqc, fastp, bwa, hisat2, stringtie, samtools,
  ciriquant, seqtk, ucsc-gtftogenepred, ucsc-genepredtobed
- conda env "rseqc": python=3.11, rseqc>=5
  (RSeQC is not compatible with the python 3.14 in the circrna env; call it
  via `conda run -n rseqc ...`)

----------------------------------------------------------------
STEP 0 - Strandedness check   (run once, one representative sample)
----------------------------------------------------------------
  subsample ~2M read pairs (seqtk) -> HISAT2 align -> sort/index BAM
  -> RSeQC infer_experiment.py vs GENCODE BED12
  Result -> library-type for all CIRIquant runs and the samplesheet column.
  Script: run_infer_strandedness_TEST.sbatch
  Conclusion for this dataset: reverse -> --library-type 2.

----------------------------------------------------------------
STEP 1 - QC
----------------------------------------------------------------
  FastQC on raw reads (optionally MultiQC to aggregate).
  Expected for RNase R data, NOT errors: uneven per-base coverage, elevated
  sequence duplication, GC skew. Do NOT deduplicate.

----------------------------------------------------------------
STEP 2 - Trim reads
----------------------------------------------------------------
  fastp, paired-end:
    --detect_adapter_for_pe            (adapter removal by overlap + sequence)
    -q 20 -u 30                        (per-read quality gate)
    --cut_right --cut_right_window_size 4 --cut_right_mean_quality 20
    -l 50                             (min length after trimming)
  Rationale: adapter + light quality trim only. Keep reads >=50 bp so BSJ
  reads retain enough anchor on each side; do not over-trim.
  QC the trimmed reads (FastQC) before mapping.

----------------------------------------------------------------
STEP 3 - Map  (BWA-MEM)
----------------------------------------------------------------
  bwa mem -T 19 -t N ref.fa R1.fq.gz R2.fq.gz > aln.sam
  - -T 19  : lower alignment-score cutoff than the default 30; raises CIRI2
             BSJ sensitivity for reads >=60 bp.
  - DO NOT sort the SAM. CIRI2 parses reads by name and relies on BWA-MEM
    supplementary / SA tags to find back-spliced reads.
  - Keep the SAM on scratch; delete after CIRI2.

----------------------------------------------------------------
STEP 4 - BSJ detection  (multi-tool consensus)
----------------------------------------------------------------
  Callers (run in parallel on the trimmed reads):
    - CIRI2:   perl CIRI2.pl -I aln.sam -O out.ciri -F ref.fa -A gtf -G log -T N
               from the BWA-MEM SAM above. First-pass filter: #junction_reads >= 2.
    - CIRCexplorer2 (implement later)
    - find_circ (implement later)
  Consensus: keep circRNAs detected by >= 2 of the 3 tools. (implement later)
    - Reconcile coordinate conventions first (CIRI2 is 1-based; BED is
      0-based half-open; find_circ / CIRCexplorer differ).
    - Output: consensus BED of BSJ coordinates.
  Rationale: single-caller false-positive rates are high and worse with
  RNase R artifacts (rolling-circle, template switching); the >=2-tool
  filter is the main precision lever. Matches the parallel nf-core/circrna
  run (--tools circexplorer2,ciri,find_circ --min_tools 2 --bsj_reads 2).

  Why CIRI2 is run separately (not just inside CIRIquant):
    - it is one of the consensus callers;
    - lets us control BWA-MEM params (-T 19);
    - CIRIquant would otherwise run its own CIRI2 with fixed params.

----------------------------------------------------------------
STEP 5 - Quantification  (CIRIquant)
----------------------------------------------------------------
  config YAML: paths to bwa / hisat2 / stringtie / samtools and to
  fasta / gtf / bwa_index / hisat_index.

  Per sample:
    CIRIquant -t N -1 R1 -2 R2 --config config.yml \
              --library-type 2 \
              -o OUTDIR -p SAMPLE \
              --bed consensus.bed          (quantify the consensus loci)
  CIRIquant internally: HISAT2 + StringTie (linear model), BWA + pseudo-
  circular reference + realignment. Outputs per circRNA: BSJ, FSJ,
  junction ratio, CPM  (SAMPLE.gtf).

----------------------------------------------------------------
STEP 6 - RNase R effect correction  (needed for cross-sample expression)
----------------------------------------------------------------
  Requires a matched RNase R(-) mock / total-RNA library per sample.
  A) CIRIquant on the RNase R(+) library:
       CIRIquant --config config.yml -1 RNaseR_1 -2 RNaseR_2 \
                 --library-type 2 --no-gene -o RNaseR -p RNaseR
  B) CIRIquant on the matched mock library, corrected against A:
       CIRIquant --config config.yml -1 mock_1 -2 mock_2 \
                 --library-type 2 -o corrected -p corrected \
                 --RNaseR RNaseR/RNaseR.gtf
  Output B = estimated pre-treatment expression (GMM fit on circRNAs seen in
  both libraries); header carries the RNase R enrichment efficiency.
  Use the corrected values for all cross-sample / tumor-vs-normal comparison.

----------------------------------------------------------------
STEP 7 - Downstream
----------------------------------------------------------------
  prep_CIRIquant  -> circRNA expression / BSJ / junction-ratio matrices
  CIRI_DE_replicate (edgeR wrapper) -> tumor vs normal differential circRNA
  circRNA host-gene / isoform annotation as needed.

================================================================
CROSS-CHECK
================================================================
Parallel nf-core/circrna run (see HNSCC_pipeline_build/run_circRNA_nfcore_TEST.slurm):
  -r <pinned commit> -profile singularity
  --tools circexplorer2,ciri,find_circ  --min_tools 2  --bsj_reads 2
  --quantification_tools ciriquant  --igenomes_ignore
Same GRCh38 / GENCODE v50 references. Used to validate the hand-built pipeline.

FIELD-STANDARD NOTE
-------------------
Two accepted approaches:
  (a) CIRIquant end-to-end, single tool (CIRI2 runs inside it).
  (b) >=2-tool consensus detection, then CIRIquant for quantification.
This pipeline uses (b) - more conservative, and consistent with the
nf-core/circrna cross-check.
